Why the threads are separate
The main loop receives UDP samples. The HTTP workers can wait on a browser or a history query without doing that work in the receive loop.
A mutex protects the snapshot pointer exchange. Each HTTP worker retains an immutable JSON string and sends it after the lock is released.

  
Connection limits
Serve() starts up to 64 connection workers. A slow request uses one worker. The listener backlog is 128. Reading the complete request has a 5-second total deadline. Sending the response has a separate 5-second total deadline. Excess connections receive HTTP 503.
Responses use HTTP/1.0. The connection closes after each request. The C++ server uses plain HTTP and has no TLS handshake.
